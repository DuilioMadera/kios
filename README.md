# kios · robótica educativa

Sitio web de demostración: robótica educativa para escuelas técnicas, institutos y universidades de Argentina.

Demo para compartir con colegas. No es el producto final.

## Qué hay en el sitio

- Presentación de plataformas (Rover Lunar 6WD, brazos robóticos, kits MCU)
- Guía rápida para elegir un kit
- Formulario de contacto (queda guardado en el navegador, no envía mail todavía)

## Repositorio

https://github.com/DuilioMadera/kios

## Cómo publicar un enlace para colegas

GitHub guarda el código. Para un enlace público:

1. Entrá a [Netlify](https://app.netlify.com) o [Cloudflare Pages](https://pages.cloudflare.com) (cuenta gratis).
2. **Import from Git** → elegí este repo `kios`.
3. Build command: `npm run build`
4. Publicá y copiá la URL (`algo.netlify.app` o `algo.pages.dev`).

Cada cambio que se suba acá puede republicarse solo.
